      룰 메모

      • 2장 핸드와 커뮤니티 5장으로 홀덤을 판정합니다.
      • 섯다는 ♥/♠의 1~10월만 사용하며, ♥는 띠, ♠는 광/동물 카드입니다.
      • 선언자가 선택한 핸드 1장과 커뮤니티 1장 중 최선 조합으로 섯다를 판정합니다.
      • 커뮤니티에 섯다 카드가 없으면 섯다 팟은 열리지 않고 홀덤으로 전체 팟을 정산합니다.
      • 리버 베팅이 끝나면 생존 플레이어별 쇼다운 준비 완료 후 자동 정산합니다.
      • 스윙은 홀덤과 섯다를 모두 이겨야 전체 팟을 가져갑니다.
      • 사구/멍사구가 나오면 섯다 팟만 자동 재경기 처리합니다.

      홀덤 족보

      스트레이트 플러시 같은 무늬 5장이 연속
      포카드 같은 숫자 4장
      풀하우스 트리플 + 원페어
      플러시 같은 무늬 5장
      스트레이트 무늬 상관없이 5장이 연속
      트리플 같은 숫자 3장
      투페어 서로 다른 페어 2개
      원페어 / 하이카드 페어 1개, 없으면 가장 높은 카드

      섯다 족보

      38광땡 3월 광 + 8월 광
      18광땡 1월 광 + 8월 광
      13광땡 1월 광 + 3월 광
      땡 같은 월 2장, 숫자가 클수록 강함
      알리 1월 + 2월
      독사 1월 + 4월
      구삥 / 장삥 1+9는 구삥, 1+10은 장삥
      장사 / 세륙 4+10은 장사, 4+6은 세륙
      사구 / 멍사구 재경기 조건. 섯다 팟만 다시 판정
